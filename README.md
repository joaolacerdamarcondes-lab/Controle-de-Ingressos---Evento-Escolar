# Controle-de-Ingressos---Evento-Escolar
Sistema web em HTML, CSS e JavaScript desenvolvido para o controle de ingressos de um evento escolar. O programa calcula o total de alunos, monitores e convidados, validando o limite máximo de 100 pessoas e a regra da direção de até 20 convidados, exibindo mensagens claras para cada situação.
